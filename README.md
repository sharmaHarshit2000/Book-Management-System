# 📚 Book Management System

A simple React Book Search App built with `useState` and basic event handling. Search for books by title from a predefined list and view details in a clean, responsive UI.

🔗 **Live Demo:** [books-managment-system.netlify.app](https://books-managment-system.netlify.app/)  
💻 **GitHub:** [github.com/sharmaHarshit2000/Book-Management-System](https://github.com/sharmaHarshit2000/Book-Management-System)

---

## 📝 About

This app lets users **search for books by title**, displaying matched results from static mock data in an organized card layout.

---

## ✨ Features

- 🔍 Real-time search by book title
- 🖼️ Book cards: cover image, title, author, publish date
- 📦 Fast, static mock data
- ⚡ Built with Vite for fast development
- 💅 Responsive UI with minimal CSS

## 🚀 Getting Started

### Prerequisites

- Node.js (v18+)
- npm

### Installation

```bash
git clone https://github.com/sharmaHarshit2000/Book-Management-System.git
cd Book-Management-System
npm install
```

### Running Locally

```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

---

## 🧾 Usage

- Type a book title (e.g., "Atomic Habits") in the search input.
- Click the Search button or press Enter.
- Matching results will appear below with cover image and details.
